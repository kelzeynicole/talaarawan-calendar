
# Talaarawan: Calendar Application

A Python-based calendar application designed to help users organize and manage their daily events.

## Features

- View monthly calendars
- Navigate between months
- Select a specific month and year
- Create new events
- View saved events
- Update existing events
- Delete events
- Store event information using CSV files

## Technologies Used

- Python
- CSV
- `calendar` and `datetime` modules
- `emoji`
- `termcolor`

## Installation and Usage

1. Clone this repository:

   ```bash
   git clone https://github.com/kelzeynicole/talaarawan-calendar.git
   ```

2. Navigate to the project folder:

   ```bash
   cd talaarawan-calendar
   ```

3. Install the required packages:

   ```bash
   pip install emoji termcolor
   ```

4. Run the application:

   ```bash
   python3 RAMOS-MachineProb.py
   ```
